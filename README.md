# Alice Childcare Services website

A responsive, single-page website built with HTML, CSS and JavaScript.

## Preview on Windows

1. Extract the ZIP archive.
2. Open the `alice-childcare-services` folder.
3. Double-click `index.html` to open the site in Edge or Chrome.
4. Resize the browser window or use DevTools device emulation to test mobile layouts.

Alternatively, open the folder in VS Code and use the Live Server extension for automatic refresh.

## Customise

- `index.html` contains the website text, section structure, and image URLs.
- `style.css` contains layout, colours, typography and mobile styles. The main palette is defined at the top.
- `script.js` controls the mobile menu, footer year and enquiry email draft.

## Before publishing

- Replace all sample text with verified details about your actual service, including age ranges, hours, fees and qualifications as appropriate.
- Replace remote stock photography with images you own or have permission to use. Do not publish identifiable photos of children without appropriate consent.
- The contact form is a **demo**: it opens a new email draft without a recipient. Add a verified destination email address or integrate a secure form service to receive enquiries. It does not send or store messages.
- Add your business address/contact details, privacy notice and any applicable legal or regulatory information.
- Google Fonts and Unsplash-hosted sample photos require internet access.
